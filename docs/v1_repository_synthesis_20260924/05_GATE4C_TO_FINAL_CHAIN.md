# Gate4C → Gate4D → Gate4E/F → final confirmation

All metrics here refer to paired **50-Hz blocks** but independent inference units are **users**. `C(x)` is the same frozen DB9 trusted-8 LDA customer. `Flip=1[C(predicted pose) != C(measured GT pose)]` is customer-output disagreement, not error against a human gesture label. Hard preservation is `1−ordinary Flip`. Balanced preservation averages reference-class preservation under the stated support rule. Fisher `e_F` is a continuous, normalized seven-dimensional customer representation error. Probability TV compares output distributions. These endpoints cannot be interchanged.
