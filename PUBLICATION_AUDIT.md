# Current publication audit — 2026-10-14

Scope: the staged current CommonPose code, latest local/server/no-retraining evidence and V5.2 manuscript, plus the existing remote-main text history. The root README has been updated to the current offline decision-fidelity study; historical frozen reports and their original source hashes are preserved.

Credential-shaped strings are scanned without exposing values. Raw signals, source pose arrays, checkpoints, fitted models, runtime dependencies, complete system-font files and authentication transport material are excluded. Participant-level CSVs contain evaluation outputs, not redistributed EMG or measured-pose arrays. Original experiment estimates and cohort definitions are not changed. The largest table is a derived factorial evaluation CSV, about 12.9 MB; this is intentional evidence, not raw sensor data.

Public copies replace machine-local path strings with role placeholders. This does not certify physical pose equivalence, actual checkpoint training membership or online service. Dataset and upstream-model access restrictions remain in force; repository-wide licensing is pending, and no new open-source licence has been selected. IEEE class/template files retain their original notices.

Every public file is checked for Python syntax or JSON parse validity where applicable, and every uploaded blob is verified by Git object hash. The publication provenance includes source and published SHA256 values. The old public V1 repository is locally backed up before the separately authorized deletion. Publication does not submit the manuscript or create a GitHub Release.
