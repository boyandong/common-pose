# CommonPose research execution

Repository artifacts are the long-term source of truth. Preserve frozen V1 lanes,
their hashes, cohorts, labels, decisions and handovers. Put supplementary work in
a separate dated lane. Never use previously examined final users as independent
confirmation of a revised method. Flip means preservation of one frozen consumer's
output, not independently labelled gesture accuracy.

## Session Hygiene Protocol

When acting as project decision maker, assess session health proactively. Remind
the user near 500K context tokens; strongly recommend handover at 800K+. Recommend
a new session at a new project phase or before complex remote background work.
After two consecutive interrupted tools/unknown outcomes, host/tool crash recovery,
or repeated retries/temporary wrappers, stop incident execution: the old session
is an archive/forensic record, not an execution workspace.

Before handover write Objective, Frozen decisions, Verified state, Scientific
evidence, Unknown/contaminated state, External runtime state (successor must
reverify), Worktree state, Next actions, Do NOT, and recommended session name.
Use PROJECT-PHASE-YYYYMMDD-PURPOSE; incidents use PROJECT-INCIDENT-YYYYMMDD-PURPOSE.
Prefer AGENTS.md, scientific specifications, handovers, manifests and git over
session prose. Do not overwrite historical frozen handovers.

## Manuscript delivery

For every future manuscript revision, deliver both the compiled PDF and its
matching LaTeX source (.tex), as requested by the user. Keep the source and PDF
from the same revision; retain required bibliography, figures and template files
so the delivered source can be compiled.
