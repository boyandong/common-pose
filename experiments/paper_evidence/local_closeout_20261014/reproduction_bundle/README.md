# Local numerical reproduction

Run `python analyze_local.py --input input --output output` from this directory. The two copied anonymized participant tables reproduce the paired intervals, joint-support sensitivity, support and missing-reference bounds. This is aggregate-result reproduction, not raw-data inference, upstream training or independent human review. Dataset/model redistribution is excluded. Pointwise intervals are exploratory; unsupported cells and all signed effects are retained. Public release requires separate review of licenses, anonymization and conference rules.
