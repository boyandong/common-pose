# Gate4F implementation lock — before Gate4F comparison

`analysis/gate4f_balanced_gate.py` is a mechanically copied Gate4E implementation. It reuses the exact Gate4E frozen loader, 19-user cohort, 36 deployment features, eight method formulas, folds, model specifications and secondary data. It changes only: class-balanced training weights for the two direct predictors, class-balanced primary endpoint/AUC and tie-break, class-balanced calibration threshold estimation, and output names. `GATE4F_PLAN.md`, `BALANCED_CUSTOMER_REQUIREMENT.md` and `METHOD_MANIFEST.json` define those differences. The original Gate4E lane is not edited. All Gate4F result JSON files and final model are written once with SHA256 sidecars. Any mechanical defect must receive a separately hashed amendment before rerun.
