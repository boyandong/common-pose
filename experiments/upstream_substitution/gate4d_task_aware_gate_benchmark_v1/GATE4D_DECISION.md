# Gate4D DEV-only benchmark decision — 2026-09-24

**GATE4D DEV BENCHMARK COMPLETE — METHOD READY FOR PROSPECTIVE VALIDATION.** This is method development on the 19 Gate4C DEV users and 654 source files only. The 8 old Gate4C VALIDATION users and every protected user remained outside Gate4D. The frozen upstream and gesture consumer were not retrained. The selected continuous layer is the consumer's 7-D Fisher `transform`; primary error is the paired GT-versus-predicted Fisher difference divided by frozen DB9 Fisher component scales. It is a diagonal scale-normalized task-space error, not a full covariance Mahalanobis distance or semantic gesture accuracy.

The four-view TTA completed 654/654. An exact-path, receipt and SHA256 check passed all 654 new TTA outputs. Subject-grouped five-fold analysis evaluated each DEV user once as held out; its 19 × 4 × 7 risk–coverage rows, 76 ranking rows, six JSON files and five plots were produced. The only code amendment before outcome analysis restored omitted per-user JSON fields and a ranking plot; it changed no scientific metric, gate, fold or model output.

All values above aggregate users first; millions of blocks are not treated as independent users. Lower `e_F` and AUC are better. Gate A is the strongest **DEV candidate for the preregistered primary continuous objective**, with TTA second. Gate A does not improve every user: `13b8b5f76d` worsens from median `e_F` 2.295 at full coverage to 2.488 at 30%; TTA also reverses there, from 2.295 to 2.656. TTA worsens user `3589743749` from 1.678 to 1.715 at 30%; its risk correlation is negative in several users. These users remain in all results.

The downstream layers tell a different story. At 30% coverage, the median user hard-output preservation changes from 0.597 at full coverage to 0.670 for Gate A, 0.616 for TTA, 0.721 for margin, and 0.752 for entropy. Thus the cheap consumer-confidence baselines favor hard decision agreement while **selecting higher Fisher task-space error**. Gate A's median balanced output preservation drops from 0.318 to 0.257 at 30%, even as its median Fisher error and probability TV improve (TV 0.260 → 0.199). TTA's balanced preservation rises to 0.350. No single gate wins every secondary representation/decision measure; class support and selective sample composition matter. These are output-preservation comparisons to the GT consumer path, not semantic gesture accuracy.

**Decision.** Preserve the frozen Gate4D negative and positive results without retuning. Advance Gate A as the DEV-selected candidate for a newly preregistered, genuinely untouched confirmation cohort, with TTA retained as its fixed comparator and the margin/entropy baselines retained to expose the continuous-versus-hard-output tradeoff. The current grouped conformal step is empirical user-group calibration and carries **no formal finite-sample coverage guarantee** for clustered within-user blocks. Before any future validation, freeze a final DEV training/calibration user allocation, model artifact and gate score, then acquire authorization for an untouched cohort. Do not reuse the already-seen Gate4C VALIDATION users as if they were new confirmation data. No new confirmation cohort was opened here.
