# Gate4D task-aware gate benchmark v1 — prospective DEV contract

**Question.** Can deployment-visible gate scores select Gate4C paired-valid blocks with lower error in the frozen downstream consumer's continuous 7-D Fisher representation? The scientific unit is the user. Gate4C remains closed and unchanged. This Gate4D branch uses only its 19 DEV users and their 654 files for development and evaluation; 8 prior VALIDATION users, protected splits and discovery user are excluded. No new confirmation cohort is authorized.

Use Gate4C's paired output arrays and receipts; do not rerun base neural inference.

**Primary layer and target.** `LAYER_SELECTION.md` defines `z_gt`, `z_pred`, and seven frozen DB9 Fisher component scales. The primary per-block error is diagonal-scale-normalized Fisher difference `e_F = ||(z_pred-z_gt)/sigma_DB9||_2`. It is a paired task-space error, not semantic gesture accuracy, nor full-covariance whitening. The continuous comparison is frozen before Gate4D outcomes.

**Gates.** Gate A reuses the exact Gate4A 48-feature deployment-visible family: current predicted trusted-8 pose, current 7-D predicted Fisher coordinate, causal first and second differences within the same record (zero at undefined starts plus validity flags), and hand side. No GT, error, future block, user ID or class label is a feature. Reuse its fixed `GradientBoostingRegressor(loss='quantile', alpha=0.90, n_estimators=100, learning_rate=0.1, max_depth=3, subsample=1.0, criterion='friedman_mse', min_samples_split=2, min_samples_leaf=1, max_features=None, random_state=0)` to predict `e_F`. Fit at most 5,000 evenly spaced paired blocks per training user in each outer fold, with no target-based sampling. On disjoint calibration users, estimate each user's 90th percentile of `e_F - predicted_risk`, then take the empirical 90th percentile across those users; add this scalar to the prediction as grouped empirical calibration. This gives a calibrated risk score for selection, **without** a finite-sample coverage guarantee for clustered blocks.

Gate B is fixed four-view TTA: identity, global EMG gain ×0.97, global gain ×1.03, and additive Gaussian noise with sigma `0.005 × RMS(official 16-channel EMG over the whole recording input window)`. Noise seed is the first eight bytes of SHA256 of `GATE4D_TTA_NOISE_V1|<source_member>`, little-endian unsigned. Use the same frozen CUDA model and Gate4C 1790-row alignment, 40-row nonoverlapping means, block indices, canonical adapter and DB9 head for each view. Identity uses the stored Gate4C `pred_api8` and must agree with newly inferred identity within `1e-5` absolute per Fisher component on paired blocks; all views are computed from the same unmodified HDF5 input. Gate score: mean across the four views of squared Euclidean distance of each Fisher vector to their Fisher centroid, in frozen DB9-normalized coordinates. No GT enters this score. Per-file TTA outputs and receipts are atomic and resumable.

Cheap baselines: negative margin of the frozen predicted-pose `decision_function` top two class scores; entropy of its already-stored 8-class probability vector. Lower gate score means higher confidence. No new neural confidence model and no unregistered upstream quality scalar.

**Subject-grouped development.** Deterministic 5-fold outer assignment: sort the 19 DEV participant IDs lexicographically and assign index modulo 5. Each user is held out exactly once. For outer fold `f`, sort remaining users; calibration users are those at positions `f, f+4, f+8` modulo their count, deduplicated (three users); all others are training users. Train/calibration/test users are disjoint. The held-out users supply no fitting, normalization or calibration data. Use all paired-valid held-out blocks for evaluation. Fitting sample caps only training rows; all 19 users still participate in outer evaluation. No random frame split.

**Evaluation.** For each gate and held-out user, sort risk ascending with stable original-block-order tie breaking. At accepted coverage `[1.00,0.90,0.80,0.70,0.60,0.50,0.30]`, accept the first `ceil(coverage × user paired-block count)` blocks. Primary: median and p90 `e_F`. Secondary: raw Fisher L2, centered Fisher trajectory correlation (GT and predicted Fisher coordinates demeaned within each record over accepted blocks, then pooled Pearson across coordinates; undefined if <2 eligible blocks), absolute discriminant-margin change, probability TV, hard output preservation, balanced preservation over reference classes with at least 30 accepted GT blocks, and accepted count. Report each user first, then user median/IQR/range; no pooled-frame inference. Plot user-median risk–coverage plus TV and hard/balanced preservation. Risk-coverage area uses the trapezoid rule on the fixed coverage grid (ascending). Per-user ranking diagnostics: Spearman(score, `e_F`), selective median and p90 reduction versus 100%, and reversal/undefined status. No binary pass threshold.

**Descriptive diagnostics.** On all paired blocks per DEV user, report per trusted-8 DOF static mean bias, centered slope of predicted on GT, centered RMSE, and centered trajectory correlation; also full-coverage continuous and downstream measures. These do not change gate selection. The Gate4C head has no UNKNOWN/AMBIGUOUS output and the cohort has no human gesture task labels; semantic accuracy is not identifiable.

**No rescue.** After freezing plan, layer, manifest, and code: no user/DOF deletion, normalization revision, view change, gate feature search, threshold tuning, head or upstream retraining, validation inspection, or protected data access. If a gate fails, report it. A mechanical implementation repair must be separately recorded and must preserve this contract.
