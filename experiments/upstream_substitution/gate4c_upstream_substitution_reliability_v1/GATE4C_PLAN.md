For each user, compute hard output preservation `mean(Y_PRED == Y_GT)` on paired valid blocks and valid coverage `paired_valid_blocks / GT_valid_blocks` after first-block exclusion. These are co-primary descriptive endpoints. The primary VALIDATION summary is the median across the 8 users, IQR (25th–75th percentiles, linear quantile rule), minimum/maximum and a 95% percentile bootstrap CI for the user median from 10,000 user-resamples with replacement, random seed `20260924`. Report every user and the fraction below the predeclared 10,000-paired-block feasibility floor; no arbitrary pass threshold is set for agreement.

Secondary per-user outputs: class-conditioned preservation against `Y_GT` for each of 8 reference classes (minimum 30 `Y_GT` blocks to include a class in the balanced average; always show support), balanced preservation as their mean, Cohen kappa, total-variation distance between `P_GT` and `P_PRED`, and the 8×8 output preservation matrix. These are **behavioral preservation**, not semantic accuracy: the emg2pose cohort has no registered human task labels for balanced accuracy, macro-F1 or task-performance delta. Record those as `NOT_IDENTIFIABLE` rather than fabricating ground truth. The frozen consumer has no UNKNOWN/AMBIGUOUS outputs, so those flip counts are `NOT_APPLICABLE`.

This localizes failures descriptively; no subgroup, angle or threshold may be removed after inspection.
