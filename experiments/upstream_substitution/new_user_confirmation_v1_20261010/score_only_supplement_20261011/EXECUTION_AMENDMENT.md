# Execution integration and backup inventory

Original scientific scripts and seals stay intact. A separate integrated controller
invokes the original five durable stages and three separately sealed supplemental
stages. Both original support and score-only support seals precede every effect
analysis. Both independent verifiers precede backup and report generation. Dispatch
outcomes are inspected by actual handles and immutable terminal receipts; an
ambiguous/missing job is never automatically relaunched.

Mutable local controller snapshots reuse the already tested finite Windows progress
replacement remedy, without changing immutable receipt save functions. Original
pipeline_supervisor.py is preserved; its imported state-publishing hook is adapted
only by this separate integrated controller. Remote scientific progress writes stay
in the original Linux implementation.

The original backup exporter enumerates its own open stdout log before printing its
final line. Including an actively written log in an immutable hash inventory can
make the copied log differ. A separate integrated exporter inventories all original
and supplementary sources of reproducibility, model copies, caches, dependencies,
static results, closed stage logs and code. It excludes only its two explicitly
named still-open export logs. After the export parent is independently terminal,
the controller separately copies/verifies those logs and the export terminal receipt
to D. Raw source files are already retained on D and are fully rehashed by the
original backup verifier. Original exporter remains unchanged.

No this-phase source qualification/inference/effect analysis had started at model
registration or Linux old-DEV admission. All 80 users, two primary comparisons,
original seven-method B reference sets, missing-data rules, thresholds, statistical
unit and reporting boundaries retain their frozen identities. Score-only is the
directly authorized secondary addition. Full original scope plus this addition,
all independent verifications, full off-host backup and reports remain required.
