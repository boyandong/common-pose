# CommonPose prospective N80 strong-baseline confirmation

This separate confirmation followed the prospectively frozen protocol. Old FINAL results informed the design and remain supplementary evidence. The historical manuscript is retained at Git `1fc75512698c92d4bd11cf52e660c8814b1ac127`.

Flip measures disagreement between one frozen consumer on measured and predicted pose. It is not independently labelled gesture accuracy. Checkpoint-specific upstream training membership is unresolved. The historical exposure audit covers saved local provenance, not all possible prior access.
