# Prospective reporting plan, prepared during source transfer

This is a reporting supplement, not a change to the frozen scientific protocol,
cohort, inference, class support rule, significance threshold or stopping rule.
At preparation, the transfer gate is closed and new-user inference has not begun.

The renderer may run only after independent result verification and complete
off-host backup verification. It checks the archived result hashes and preserves
the original manuscript at Git 1fc75512698c92d4bd11cf52e660c8814b1ac127.
Its output is a separate prospective confirmation supplement.

The report contains the full enrollment and source flow, qualification receipt,
both prescribed primary contrasts with absolute risks, paired effect median and
descriptive CI, positive/zero/negative/missing counts, effective nonzero counts,
two-sided sign p values and joint decision. Missing pairs remain missing. A
conditional subset p value cannot establish full-cohort confirmation.

All 80 enrolled users appear in the primary table. All seven methods appear in
the canonical 30% absolute-risk table. Original DEV deployment thresholds and
their achieved coverage remain separate from rank-matched coverage. All twenty
seeds are reported as conditional tie sensitivity, with no best-seed selection
and no seed-pooled independent sample size. Detailed seven-coverage, per-class,
within-predicted-class and seed rows remain linked in the result archive.

No additional inferential test or new primary hypothesis is introduced. Medians
and ranges added for presentation are descriptive. The report preserves old
FINAL exposure, unresolved upstream membership, the scoped history audit, and
the definition of Flip as preservation of one frozen consumer's output.

Positive, NOT_CONFIRMED and EVIDENCE_INSUFFICIENT decisions use the same report
format and require the same provenance and verification checks. A structural
qualification failure stops the experiment and requires a separate flow/failure
report; it is not reported as a successfully computed efficacy result.
